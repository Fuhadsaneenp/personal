Custom EMS Platform

AI-Assisted Development Biometric Integration Real-time Monitoring Payroll Engine

Project Overview

This proprietary Employee Management System (EMS) was designed and implemented for our organization using advanced prompt engineering workflows (via Antigravity Codex and Claude). The core directive was to eliminate manual roster calculations by linking software-based dashboards directly to physical biometric hardware.

The platform successfully monitors attendance in real-time, matching biometric fingerprint check-in and check-out handshakes to verified employee accounts. The system automatically processes attendance indexes, tracks leave policies, handles correction requests, and generates monthly company-wide payroll runs.

Application Interfaces

Admin Dashboard

Provides summaries of present/absent counts, check-in averages, punctuality counters, and active work tasks.

Employee Attendance Grid

A personalized, color-coded calendar visualizing WFH tags, approved leaves, late check-ins, and weekend slots.

Punch Log Details

Detailed modal presenting check-in/out timestamps, hours logged, and option to request punch corrections.

Live Biometric Logs

Real-time raw biometric punch stream displaying synced employee codes, punch statuses, and direct timestamps.

Automated Payroll Run

Interactive wizard enabling administrators to run monthly payroll and generate payslips based on calculated work hours.

Core Functionality & Scope

  • Biometric Device Integration: Links direct hardware API responses to the SQL database tables, updating check-in states instantly.
  • Real-Time Data Streaming: Monitors active punch activities across teams to display present/absent statistics for managers on daily dashboards.
  • Self-Service Attendance Portal: Permits staff to audit monthly records and submit correction requests directly to administration.
  • Automated Payroll Calculation: Computes regular pay, deductions, WFH credits, and unpaid leaves automatically based on biometric log aggregates.
